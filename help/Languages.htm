Language Support

SatisCode IDE provides support for a wide variety of programming languages, featuring built-in Language Server Protocol (LSP) engines for deep code intelligence.

LSP-Powered Languages

Python (Powered by Pyright)

Python editing in SatisCode is powered by Microsoft's Pyright language server (bundled in PythonLSP/). Features include:

  • Real-time Static Type Checking: Instant syntax and type error detection reported in the Problems panel (Ctrl + .).
  • IntelliSense & Auto-Completion: Context-aware completion suggestions for modules, functions, variables, and methods.
  • Hover Documentation: Hover over any symbol to inspect its signature, type annotations, and docstrings.
  • Go to Definition: Jump directly to symbol definitions across your workspace.

C and C++ (Powered by clangd)

C and C++ files are powered by LLVM's clangd server, providing fast background indexing, error diagnostics, auto-completion, and navigation.

Syntax-Supported Languages

SatisCode also supports syntax highlighting and smart indentation for:

  • JavaScript & TypeScript
  • HTML & CSS
  • JSON & JSONC
  • Plain Text

Switching Languages

SatisCode automatically detects language based on file extension (such as .py for Python or .cpp for C++). You can also manually switch the active language at any time using the language selector dropdown in the top toolbar.
