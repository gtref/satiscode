Language Support

Satiscode detects the editor language from a file's extension. You can also choose a language manually from the toolbar, or select Auto to restore automatic detection.

Language Services

Python (Powered by Pyright)

Python files (.py) use Pyright for diagnostics, completion, hover information, and go-to-definition. Python must be installed for Python language services to work correctly.

  • Diagnostics are listed in the Problems panel, toggled with Ctrl + ..
  • Completion suggestions are available while editing.
  • Hover over symbols for information and use go-to-definition to navigate.

C and C++ (Powered by clangd)

C and C++ files (.c, .cc, .cpp, .cxx, .h, .hh, .hpp, and .hxx) use clangd for diagnostics, completion, hover information, and go-to-definition.

JSON and XML

JSON files (.json) use FIXSON for diagnostics, completion, and hover information. JSONC (.jsonc) uses the editor's built-in support without strict FIXSON validation.

XML, XSD, XSL, XSLT, SVG, and plist files use FIXML for diagnostics, element completion, and hover information.

Syntax-Supported Languages

Monaco provides editor support for these additional languages and formats:

  • JavaScript and TypeScript, including JSX and TSX
  • HTML, CSS, and SCSS
  • JSONC
  • Markdown files (.md and .markdown) with Preview and Edit modes
  • Plain Text

Language Server Availability

If a language server is unavailable, the file can still be opened and edited, but that server's diagnostics and code intelligence will not be available. A clean source checkout may not contain the clangd or Pyright server files; see the development notes in the project README.
