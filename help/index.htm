SatisCode is an IDE that was designed to be lightweight and efficient. It runs self-contained without requiring external libraries or constant internet connectivity. It comes equipped with built-in Language Server Protocol (LSP) capabilities for C/C++ via clangd and Python via Pyright.

Browse the topics above for guides on Python type-checking and autocompletion, C/C++ compilation database support, editor navigation, and keybinds.
