SATISCODE KEYBINDS

The standard keyboard shortcuts available in SatisCode IDE are:

Keybind Action
Ctrl + N Create a New File Tab
Ctrl + O Open File
Ctrl + K Open Folder Workspace
Ctrl + S Save Active File
Ctrl + Shift + S Save As...
Ctrl + F Find in Current File
Ctrl + . Toggle Problems Diagnostics Panel
