General Help & Features

Welcome to the general reference guide for SatisCode IDE. SatisCode is designed to be a lightweight, responsive, and distraction-free code editor.

Core Features

  • Language Intelligence (LSP): Integrated Language Server Protocol support for Python (Pyright) and C/C++ (clangd), offering diagnostics, hover, definition, and completions.
  • Tab Management: Easily work with multiple files using tabs. Open, close, or create tabs with keyboard shortcuts or the tab bar.
  • File Explorer: Browse folder directories, explore files, and navigate your project workspace.
  • Problems Panel: View errors and warnings emitted in real time by Pyright and clangd. Toggle the panel with Ctrl + ..
  • Find in File: Quickly search within active files using Ctrl + F.
  • Themes & Localization: Easily switch between Dark and Light themes and multiple interface languages.
