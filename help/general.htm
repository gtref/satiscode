General Help & Features

Satiscode is a Windows code editor for working with individual files or a folder workspace.

Core Features

  • Open and save files: Use the toolbar or keyboard shortcuts to create, open, and save files.
  • Tabs and Explorer: Keep several files open and browse a folder workspace in the Explorer sidebar.
  • Language services: clangd, Pyright, FIXSON, and FIXML provide diagnostics and code intelligence for supported file types.
  • Problems panel: Review diagnostics and select an entry to navigate to its location. Toggle the panel with Ctrl + ..
  • Find in file: Search the active file with Ctrl + F.
  • Markdown: Switch between rendered preview and source editing for Markdown files.
  • Git: Review repository status and commit history, stage changes, commit, pull, push, and view blame.
  • Themes and interface language: Choose Dark, Light, or High Contrast themes, and use English or Spanish.
