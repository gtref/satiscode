## Becoming a Contributor

We welcome contributions of all types: bug fixes, language server integrations, theme improvements, docs updates, and UI refinements.

Check out our [Contributing Guide](CONTRIBUTING.md) to get started. Once your pull request has been merged, feel free to submit a PR adding your name and GitHub profile to this file!
